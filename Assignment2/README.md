# Assignment 2: Sales Analytics on CSV Data

Loads sales transactions from CSV, validates every row, and answers
analytical questions (totals by region, averages by category, top
salespersons, monthly trends, date-range and multi-dimension queries) using
functional programming with the Python standard library.

## Requirements

- Python 3.10 or newer
- No runtime dependencies (standard library only)
- Development tools are pinned in `requirements.txt`

## Setup

Run every command from this `Assignment2` folder.

Windows (PowerShell):

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

If PowerShell blocks `Activate.ps1`, run
`Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` first (affects
the current window only).

macOS / Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Running the demo

```bash
python -m sales_analytics                                    # data/sales_sample.csv
python -m sales_analytics data/sales_malformed.csv           # lenient: reports bad rows
python -m sales_analytics data/sales_malformed.csv --strict  # stops at the first bad row
python -m sales_analytics --start 2026-01-01 --end 2026-03-31 --region West --top 5
```

## Running the tests

```bash
python -m pytest                                    # full suite
python -m pytest --cov --cov-report=term-missing    # with coverage
python -m ruff check .                              # lint
```

## Design decisions

- **Standard library instead of pandas.** The specification lists `reduce`,
  `groupby`, `Counter` and comprehensions; plain Python shows each one
  explicitly and keeps the project free of runtime dependencies.
- **`Decimal` for money.** Floats cannot represent cents exactly
  (`0.1 + 0.2 != 0.3`) and round 2.675 down to 2.67.
- **Immutable records and analyzers.** Filters return new analyzers, and
  every object is safe to share between threads.

## Assumptions

- "Average sale" means the mean `total_amount` per transaction in a category.
- Top salespersons are ranked by total revenue; ties are broken by name.
- Salesperson names uniquely identify a salesperson.
- Date ranges are inclusive at both ends.
