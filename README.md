# Uptime Coding Assessment: Producer-Consumer and Sales Analytics

Two Python assignments in one repository. Each package is self-contained and
uses only the Python standard library.

| Assignment | Package | Run it |
| --- | --- | --- |
| 1. Producer-consumer with thread synchronization | `producer_consumer/` | `python -m producer_consumer` |
| 2. Sales analytics on CSV data | `sales_analytics/` | `python -m sales_analytics` |

## Requirements

- Python 3.10 or newer
- No runtime dependencies (standard library only)
- Development tools (pytest and plugins, ruff) are listed in `requirements.txt`

## Setup

```bash
git clone <repository-url>
cd <repository-folder>
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Running the tests

```bash
pytest                                       # full suite (10 s per-test timeout)
pytest --cov --cov-report=term-missing       # with coverage
pytest tests/test_shared_queue.py tests/test_manager.py --count=50   # repeat concurrency tests
ruff check .                                 # lint
```

### Assumptions

- Item payloads are immutable (str, int, tuple). `Item` is a frozen
  dataclass, but freezing is shallow, so a mutable payload is not protected.
- A stop aborts the transfer: items still queued are not delivered, and
  `TransferResult.undelivered` reports them.
- With several producers and consumers, global delivery order is not
  guaranteed; the queue itself is strictly FIFO.
- A `DataTransferManager` is single use, because Python threads cannot be
  restarted.

### Design decisions

- **Standard library instead of pandas.** The specification lists `reduce`,
  `groupby`, `Counter` and comprehensions; plain Python shows each one
  explicitly and keeps the project free of runtime dependencies.
- **`Decimal` for money.** Floats cannot represent cents exactly
  (`0.1 + 0.2 != 0.3`) and round 2.675 down to 2.67.
- **Immutable records and analyzers.** Filters return new analyzers, and
  every object is safe to share between threads.
- **Lenient and strict loading.** <!-- TODO: one sentence each. -->

### Assumptions

- "Average sale" means the mean `total_amount` per transaction in a category.
- Top salespersons are ranked by total revenue; ties are broken by name.
- Salesperson names uniquely identify a salesperson.
- Date ranges are inclusive at both ends.
